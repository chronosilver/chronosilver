### 👩‍🎨 About

I started as a **designer**, moved into **frontend development**, and later led a frontend team.
That path shapes how I work: I speak both Figma and TypeScript, so design decisions
survive the trip to production — consistent, reusable and pixel-perfect.

### 🎯 What I Do

* 🧩 **UI components on the fly** — components assembled from config and data, with typed APIs that make wrong usage a compile error.
* 🎨 **Design systems** — design tokens as a single source of truth, component libraries, usage rules and documentation.
* 🔁 **Migration & scaling** — moving products onto a design system, evolving it over time and scaling it across products and brands.
* 🤝 **Design ↔ Dev bridge** — clean handoff from Figma, pixel-perfect implementation, shared language between designers and engineers.
